a4sx provides a platform to save and share Claude Code and Codex CLI sessions. Users can resume Claude Code sessions on any machine, and buy or sell sessions in an open marketplace. The service offers free browsing of shared sessions and aims to foster collaboration among developers using AI coding tools.

**Areas:** Marketplace · AI Agents

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for a4sx: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
